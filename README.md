# 勇者エイヤの漢字冒険　Ver.1.1

魔王モジクライにうばわれた1026の漢字を取りもどす、小学校漢字の学習ゲームです。
ブラウザだけで動きます（インストール不要・サーバー不要）。

## 遊び方

- 1〜6年の「国」と、漢字10字ずつの「町」をめぐる冒険です。
- 1字につき3回正解で「覚えた」になります。町の漢字をすべて覚えると門番があらわれ、たおすと町に文字がもどります。
- 国の町をすべて取りもどすと「国の王」が出てきます。たおすと漢検の級に対応した称号（1年＝10級 〜 6年＝5級）がもらえます。
- 問題は4種類です：読み・意味・書き（4択）・書き順（何画目？）。制限時間は5秒（書き順は10秒）です。
- 今日のクエスト、宝箱、なかまモンスター、そうび、さびた漢字（間をあけた復習）、おやすみの盾があります。

## 操作

- 画面の高さはスマホ・iPadに合わせて固定されます（ページ全体はスクロールしません）。
- よく押すボタンは画面の下（親指の届く範囲）に集めてあります。
- ホーム：左右にスワイプで国（学年）をきりかえ
- バトル：答えたあと、上にスワイプで つぎの問題へ
- ずかん・そうびなど：右にスワイプで ホームにもどる
- ホーム画面に追加すると、アプリのように全画面で遊べます（iPhone：共有ボタン →「ホーム画面に追加」）。

## 公開のしかた（GitHub Pages）

1. このフォルダの中身（`index.html` `README.md` `.nojekyll`）をリポジトリにアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。
