# 勇者エイヤの漢字冒険　Ver.1.4

魔王モジクライにうばわれた1026の漢字を取りもどす、小学校漢字の学習ゲームです。
ブラウザだけで動きます（インストール不要・サーバー不要）。

## 遊び方

- 1〜6年の「国」と、漢字10字ずつの「町」をめぐる冒険です。
- 町の漢字をすべて覚えると門番があらわれ、たおすと町に文字がもどります。
- 冒険は必ず1年生の国から始まります。国の町を半分取りもどすと「国の王」が出てきます。たおすと漢検の級に対応した称号（1年＝10級 〜 6年＝5級）がもらえ、次の学年の国が開きます。すべての漢字を覚えなくても先に進めます。
- 6年生の国の王をたおすと「真の勇者への道」が開きます。全学年の町をすべて取りもどすと真の魔王があらわれ、たおすと称号「真の勇者」がもらえます。
- 問題は4種類で、どれも1問の中で4つの小問を出てきた順に答えます。
  - 読み・書き・書き順：小問ごとに4択の選択肢が入れかわります（制限時間は1問で20秒、書き順は40秒）。
  - 意味あわせ：4つの熟語ボタンから、出てきた意味の順にタップします（選ばれたボタンは減っていきます。20秒）。
- 1字につき3回正解で「覚えた」になります。数えるのは1回のバトルで1字1回までなので、何回かに分けて復習することになります。
- 意味あわせの4つの熟語は、同じ漢字を使う熟語や、意味の種類（人・場所・もの・こと・気持ちなど）が近い熟語を組み合わせて出します。
- 今日のクエスト、宝箱、なかまモンスター、そうび、さびた漢字（間をあけた復習）、おやすみの盾があります。

## 操作

- 画面の高さはスマホ・iPadに合わせて固定されます（ページ全体はスクロールしません）。
- よく押すボタンは画面の下（親指の届く範囲）に集めてあります。
- 上下のスクロールはほぼなく、どの画面も1画面に収まります。
- ホーム：左右にスワイプで国（学年）をきりかえ
- ずかん・なかま・そうび：左右にスワイプでページをめくる
- バトル：答えたあと、上にスワイプで つぎの問題へ
- ホーム画面に追加すると、アプリのように全画面で遊べます（iPhone：共有ボタン →「ホーム画面に追加」）。

## 公開のしかた（GitHub Pages）

1. このフォルダの中身（`index.html` `README.md` `.nojekyll`）をリポジトリにアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。

## 記録（セーブ）について

- 1問答えるたびに、遊んでいる端末のブラウザに自動で保存されます。
- 端末やブラウザが変わると、記録は引き継がれません。
- ブラウザのサイトデータを消すと、記録も消えます。
